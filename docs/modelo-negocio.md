# Lienzo de modelo de negocio (Business Model Canvas)

Primer entregable pedido por el profesor, antes del anteproyecto. Fuente: Documento Maestro v2. Versión visual: artifact «Lienzo de modelo de negocio ASCENDX AI».

| Bloque | Contenido |
|---|---|
| **Socios clave** | Universidad, programa de Tecnología en Desarrollo de Software y asesor · Render (servidor) y Neon (PostgreSQL) · proveedor de IA (por seleccionar) · Google ML Kit y React Native / Expo · GitHub · usuarios de prueba · SIC (Ley 1581 de 2012) y Superintendencia Financiera (tasa de usura) |
| **Actividades clave** | Desarrollo de la app y la API · motor de cálculo financiero verificable · integración de IA con datos controlados y OCR · seguridad y protección de datos · pruebas con usuarios y documentación |
| **Recursos clave** | Desarrollador y asesor · React Native, Expo, Node.js, PostgreSQL, Prisma, IA, ML Kit · nube con planes gratuitos · motor de cálculo con pruebas · marca ASCENDX AI · normativa colombiana |
| **Propuesta de valor** | Convertir ingresos, gastos y deudas en un plan concreto para varias metas y mostrar con cifras verificables si conviene ahorrar o financiar: 1) capacidad de ahorro con reglas explícitas; 2) metas múltiples con reparto por prioridad y fecha; 3) simulador ahorro vs. crédito explicado por un mentor de IA que solo usa cifras del sistema. Herramienta educativa, no asesoría profesional. |
| **Relación con clientes** | Autoservicio guiado · mentor de IA · gamificación moderada (hitos, progreso) · confianza: supuestos visibles, consentimiento y control de datos |
| **Canales** | App Android (Expo Go, APK; a futuro Google Play) · universidad y eventos académicos · redes sociales y recomendación · GitHub |
| **Segmentos de clientes** | Mayores de 18 en Colombia con ingresos propios que quieren alcanzar una meta: estudiantes que trabajan, empleados jóvenes, independientes · comunidad académica evaluadora |
| **Estructura de costos** | Tiempo de desarrollo y asesoría · nube (gratis al inicio) · API de IA con límites · cuenta de Google Play (pago único) · servicio de correo (pendiente) · equipos e internet |
| **Fuentes de ingresos / Beneficios** | Hoy: sin ingresos directos; decisiones financieras más informadas; aporte académico. Futuro: plan prémium opcional, alianzas de educación financiera; sin venta de datos ni publicidad de créditos. |
